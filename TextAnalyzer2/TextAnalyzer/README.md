# Text Analyzer Kata

A simple Java kata for practicing file processing, Java Streams, and Functional Interfaces.

## Goal

Read a text file and calculate basic statistics.

The application should report:

- Number of words
- Number of characters (excluding whitespace)

## Example

### Input

```
Hello Java World
Streams are awesome.
```

### Output

```
Words: 5
Characters (without spaces): 32
```

## Requirements

- Use Java 21
- Read the text from a file
- Ignore whitespace when counting characters
- Keep the implementation clean and readable

## Suggested Topics

- Files API
- Stream API
- Predicate
- Function
- Optional
- String processing

## Bonus Challenges

- Count lines
- Count sentences
- Find the longest word
- Find the shortest word
- Find the most frequent word
- Ignore punctuation
- Ignore letter case
- Display words sorted by frequency

## Learning Objectives

By completing this kata you will practice:

- Reading files in Java
- Processing text
- Using Streams effectively
- Applying Functional Interfaces
- Writing clean and testable code
